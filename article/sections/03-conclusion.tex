\section{Consequences and open problems}
\label{sec:conclusion}

\subsection{Consequences}

Summarise what \cref{thm:main} gives that was not available before.
State each consequence as a numbered corollary or proposition rather
than as prose, so that it can be cited.

\subsection{Limitations}

State honestly where the argument stops. If a hypothesis is used only
in one step, say which step, and say whether it is plausibly removable.

\subsection{Open problems}

\begin{enumerate}
  \item Does \cref{thm:main} hold without the local compactness
        hypothesis on $X$?
  \item Can the exponent $1/2$ in \cref{eq:main} be improved when
        $\mu$ is atomless?
  \item Is the equality case characterised by \cref{cor:consequence}
        when $\mu(X) = 1$?
\end{enumerate}
